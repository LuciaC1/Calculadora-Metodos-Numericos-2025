# Métodos Numéricos 2025

Implementación de algoritmos de **métodos numéricos** desarrollados durante la cursada de **Análisis Numérico 2025** (Ingeniería en Informática, Universidad Católica de Santiago del Estero).

El repositorio reúne la resolución de las prácticas de la materia: cada unidad se resuelve con algoritmos propios, pensados para entender cómo funcionan los métodos por dentro y no solo para obtener un resultado.

## Contenido

| Unidad | Tema | Estado |
| ------ | ---- | ------ |
| 1 | Raíces de funciones | Implementada |
| 2 | Sistemas de ecuaciones | Implementada |
| 3 | Ajuste de curvas | Implementada |

## Qué se trabaja en cada unidad

- **Raíces de funciones:** métodos para encontrar los ceros de una función, comparando su convergencia y precisión.
- **Sistemas de ecuaciones:** métodos para resolver sistemas lineales de forma numérica.
- **Ajuste de curvas:** aproximación de datos mediante funciones (próximamente).
- **Integración numérica:** cálculo aproximado de integrales definidas (próximamente).
